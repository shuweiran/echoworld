## 一、已发生 500 事实清单（日志证据）

| 时间 | 实例 | 异常类型 | 溢出位置 | 触发场景 |
|------|------|----------|----------|----------|
| 16:35:11 | 26236 | DataIntegrityViolation | **scenes.name** VARCHAR(255) | AI 生成剧本 → 落库 |
| 17:15:01 | 3756 | DataIntegrityViolation | **scripts.name** VARCHAR(255) | AI 生成剧本 → 落库（主人复测） |

- 两条均为 `Value too long for column "NAME CHARACTER VARYING(255)"`，值开头 `剧本：某个暴雨夜，几名同学…`（**268 字符**）
- **非业务 500 的 ERROR 共 12 条**（boot2 的 10 条 + boot11 的 2 条）：全部 `java.io.IOException: 你的主机中的软件中止了一个已建立的连接`——客户端断开（浏览器/curl 中断），非数据问题，低风险

**结论：业务 500 只有 1 个根因，但影响 2 张表，P-0803-G 只修了 1 张。**

## 二、根因链（完整）

```
LLM 生成剧本 JSON（prompt 未约束 title 长度）
  → metadata.title = 268 字符（"剧本：某个暴雨夜，几名同学…"整段描述被写进 title）
  → ScriptGameService.initGame L338: game.name = ScriptSchemaV1.title(script)   ← 无长度规约
  → 同一 title 双写两张表：
      ① saveScene(...) → scenes.name          ← P-0803-G 已修（列宽 2000 + 截断 500）
      ② saveScript("剧本：" + game.name)       ← "剧本：" 前缀后 271 字符 > 255 → 17:15 复现 500
```

**关键发现：P-0803-G 修复不完整**——只修了 scenes 表，scripts 表同源同炸。

## 四、系统性缺陷（4 项）

1. **无全局异常处理**：全库无 `@RestControllerAdvice`/`@ExceptionHandler` → 500 返回 Spring 默认 HTML/空 body，前端只能显示裸 "HTTP 500"（client.ts 的 `err.detail` 分支拿不到结构化信息）
2. **落库层无统一长度防御**：仅 saveScene 有截断（P-0803-G），saveScript/saveCharacter 裸写
3. **LLM 输出无长度规约**：`ScriptSchemaV1.title` 直接透传 LLM 值；prompt 仅描述"剧本名称"未限长度
4. **观察项**：SceneController 内存 `scenes` 列表与 DB 不同步（删除只删 DB、重启丢内存态、列表读内存）——非 500 直接原因，但属数据一致性隐患

## 五、建议方案（按优先级，**待主人确认后实施**）

| 优先级 | 方案 | 改动 | 效果 |
|--------|------|------|------|
| **P1** | scripts.name 扩列 2000 + saveScript 截断 500 | ScriptEntity + DatabaseService（同 P-0803-G 模式，2 文件） | 修复当前 500 |
| **P1** | saveCharacter 同样截断防御 | DatabaseService | 堵用户 API 超长名 500 |
| **P1'** | **源头治理**：ScriptSchemaV1.title 解析后规约（>100 截断） | 1 文件 | 一劳永逸，scenes/scripts/对局结果/广播全链路受益 |
| P2 | @RestControllerAdvice 全局异常 → 结构化 JSON {error, detail} | 新增 1 类 + controller 无关 | 前端友好显示，不再裸 "HTTP 500" |
| P2 | prompt 约束 title ≤ 50 字 | ScriptService prompt | 降低 LLM 超长概率 |
| P3 | controller 内存 scenes 同步改造 | SceneController | 数据一致性（观察项） |
