# Roleplay-Java UI 视觉规范与图标/标签清单

> 版本：v1.0 · 日期：2026-08-22 · 适用范围：桌面版、浏览器版、一般模式 2D、剧本杀/Gal 界面
>
> 目标：把现有深色 React + Phaser 界面统一为“幻境之书”叙事角色扮演产品视觉系统。本文是实现约束，不要求一次性重做全部页面；具体场景（如晨雾镇）不承担产品品牌职责。

## 1. 视觉定位

核心气质：深夜侦探、晨雾小镇、轻像素、可读而不喧闹。

- 深色蓝黑底，模拟夜间桌面游戏环境
- 雾蓝和紫色承载世界氛围
- 金色承载线索、重要剧情和奖励
- 青色承载可交互、导航和确认
- 红色只用于危险、错误、死亡和不可逆操作
- 图标用于快速识别，文字用于准确表达；不能只依赖颜色

不采用：高饱和渐变铺满页面、每个按钮使用不同图标风格、纯 emoji 作为最终品牌图标、过度玻璃拟态导致文字对比度不足。

## 2. 画布与桌面窗口

| 项目 | 规范 |
|---|---|
| 逻辑分辨率 | 1280×720，16:9 |
| 推荐窗口 | 1280×720 内容区；外框由桌面壳处理 |
| 最小兼容 | 960×540，保持 16:9 |
| 设计网格 | 8px 基准；间距优先使用 8/16/24/32px |
| Phaser 缩放 | FIT + 居中，禁止拉伸变形 |
| 窗口模式 | 窗口化、无边框全屏、普通全屏可切换 |
| 缩放原则 | 面板可折叠，核心地图和对话不变形 |

信息层级：①当前阶段、目标、可执行动作；②角色/地图/对话主内容；③线索、关系、状态；④调试、网络、版本等系统信息。

|---|---|---:|---|

| 次面板 | --color-panel-2 | #1b2944 | 输入框、按钮、选中底 |
| 辅助面板 | --color-panel-3 | #232f4b | 悬停、步骤圆点 |
| 主文字 | --color-text | #e8eef9 | 标题、正文 |
| 次文字 | --color-text-dim | #93a1bd | 说明、时间、辅助信息 |
| 弱文字 | --color-text-dim2 | #5b6b8c | 占位、不可用信息 |

颜色使用上限：一个组件最多一个主强调色；状态色只表达状态，不作为装饰渐变。

## 4. 字体与文字

- 中文正文使用系统无衬线字体，保证 Windows 无额外安装也能显示。
- 标题使用较高字重，不使用花体；剧情标题可少量使用展示字体，但必须有系统回退。
- 正文 14px；辅助 12px；小标签 11–12px；页面标题 20–24px；主标题不超过 32px。
- 正文行高 1.55，标签行高 1.2。
- 重要状态同时使用图标、文字和颜色，例如 “✓ 已完成”，不只显示绿色。
- 按钮 2–6 个字，标签 2–4 个字，提示不超过两行。

## 5. 组件形态

### 面板

- 默认背景 --color-panel，边框使用低透明度 --color-border。
- 默认圆角 8px；主要抽屉/弹窗 12px；避免大量使用 20px 以上圆角。
- 阴影仅用于浮层和抽屉：0 8px 30px rgba(0,0,0,.45)。
- 面板标题采用“图标 + 标题 + 可选数量/状态”。

### 按钮

| 类型 | 外观 | 使用场景 |
|---|---|---|
| 主按钮 | 强调色实底、深色文字 | 开始、确认、进入下一阶段 |
| 次按钮 | 次面板底、边框 | 返回、查看、切换 |
| 图标按钮 | 30–36px 正方形 | 音量、全屏、收起、设置 |
| 危险按钮 | 红色低透明底 | 删除、结束对局、拒绝 |
| 禁用按钮 | 低对比度、不可 hover | 条件未满足 |

按钮必须有 hover、pressed、disabled 三态；图标按钮必须有 tooltip 或 aria-label。

### 卡片、徽章、芯片

- 角色卡：头像/首字、姓名、身份状态、当前关系或在线点。
- 任务卡：目标图标、标题、进度、下一动作。
- 状态胶囊：只承载短状态，不放长句。
- 线索卡：编号、标题、地点、持有状态、是否可转交。
- 重要卡片可用左侧 3px 相位色条，避免整张卡片高饱和。

## 6. 图标系统

### 图标规则

- 最终 UI 图标采用统一的线性 SVG/图标字体风格，默认 16px，重点操作 20px，地图标记 24px。
- 线宽 1.75–2px，端点圆润；同一层级不混用实心、像素、emoji 三种风格。
- 线索和地图图标可以保留少量像素化装饰，但必须有线性小尺寸版本。
- 图标不单独承担危险含义，必须配文字或 tooltip。
- emoji 仅作为当前兼容层和快速原型方案，品牌版逐步替换。

## 8. 页面落地规则

### 首页/大厅

- 首屏只突出“继续游戏”“开始新游戏”“剧本杀”“一般模式 2D”。
- 版本号放右下角或设置入口，不抢主标题。
- 游戏图标采用“一条连续叙事路径 + 一个分岔节点”的抽象构图；它表示没有预设剧本，选择让故事向不同方向展开。小尺寸只保留路径和节点。

### 一般模式 2D

- 地图是主视觉，UI 使用半透明浮层，不能覆盖角色和碰撞信息。
- 角色名、在线点、会话组标记使用统一图标，不在地图上堆长文本。
- 右侧对话栏标题显示“会话组图标 + 参与者 + 旁听/加入状态”。

### 剧本杀

- 顶部固定显示当前阶段和剩余行动点/关键资源。
- 左侧显示玩家/角色，中央显示剧本内容，右侧显示线索、目标和操作。
- 投票、揭晓、结束对局属于高风险动作，必须使用确认弹窗和危险色。

### Gal/像素视图

- Gal 粉、像素青、像素金只用于 Gal 主题，不扩散到普通面板。
- 对话框保持高对比度；角色名、发言正文、选择项三层字号明显区分。
- 像素装饰不进入功能状态判断，避免装饰与可点击元素混淆。

## 9. 游戏图标与品牌资产清单

| 资产 | 规格建议 | 用途 |
|---|---|---|
| 应用主图标 | 1024×1024 PNG + SVG 源稿 | exe、安装包、任务栏 |
| 小图标 | 256/128/64/32/16 多尺寸 | 窗口、快捷方式、系统托盘 |
| 游戏 Logo | 横版透明 PNG/SVG | 首页、启动页、安装程序 |
| 启动图 | 1920×1080 | 启动画面，可选 |
| 阶段图标 | 24/20/16px SVG | 搜证、讨论、投票、揭晓 |
| 状态图标 | 16/20px SVG | 在线、静默、危险、完成 |
| 地图标记 | 24/32px SVG 或 Phaser 纹理 | 出生点、热点、入口、线索 |

Logo 和主图标建议：圆角方形深靛底、一条连续路径、一个分岔节点。不要绑定任一城镇、地图、存档或游戏模式，也不要加入书页、人物、地图、狼头或其他装饰主题符号。

## 10. 实现验收清单

- [ ] 新增 UI 不直接写色值，使用全局语义 Token。
- [ ] 图标有统一尺寸、线宽、对齐方式和 tooltip。
- [ ] 状态不只依赖颜色，至少同时有文字或图形。
- [ ] 1280×720 下无核心按钮被裁切。
- [ ] 960×540 下侧栏可折叠，地图/对话仍可操作。
- [ ] 16:9 以外的窗口不拉伸 Phaser 画面。
- [ ] 剧本杀阶段、线索、投票、危险操作都使用本清单中的标签。
- [ ] 桌面更新状态沿用 [发现新版本] → [正在下载] → [需要重启] 状态链。
- [ ] 最终品牌图标不依赖外部网络资源。
