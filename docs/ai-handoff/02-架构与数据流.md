# 02 — 架构与数据流
> 同步时间戳：2026-07-31 16:57（本文件为快照，冲突以项目内活文档为准）


## 核心数据流（每 tick）
```
每 tick → SimulationOrchestrator
  → WorldDirectorService（想做什么：角色目标）
  → InteractionDetector（谁知道什么：TrackScore，阈值 40）
  → TrackDirectorService（轨道分配：MERGED / WEAK / ISOLATED）
  → MovementConstraint（怎么移动：聚集 / 听觉带 / 避让）
  → ConversationGroup → TrackStrategy（隔离上下文）→ LLM → SSE
```

## 模块职责（改动前先确认归属）
| 包/类 | 职责 | 不负责 |
|---|---|---|
| `simulation/track/` | 轨道计算：TrackAssignment / SpatialTrackResolver（距离→轨道）/ InteractionDetector（TrackScore）/ EavesdropSummarizer（摘要） | 移动、对话 |
| `simulation/director/` | 导演层：WorldDirectorService（目标）/ TrackDirectorService（分配+secretAgents） | 直接移动角色 |
| `simulation/conversation/` | 对话：ConversationManager / TrackStrategy（统一 GROUP_DISCUSSION+DEBATE）/ ModeClassifier（多群组） | 轨道判定 |
| `simulation/movement/` | MovementConstraint（轨道→运动约束，纯规则零 LLM）/ MovementTarget | 对话内容 |
| `service/` | RouterService（身份锁定【你的身份】）/ ArbiterService（审批+脱敏）/ ScriptGameService（剧本杀）/ WerewolfService（狼人杀） | 互相不越界 |
| `controller/` | REST 层（17 个 Controller，110 端点） | 业务逻辑 |

## 三种轨道模式（需求第九条）
| 轨道 | 上下文 | 运动 | 判定依据 |
|---|---|---|---|
| **MERGED** | 全文可见 | 聚集（组质心±20 偏移） | 距离 < 阈值 |
| **WEAK** | 仅摘要（隐藏细节） | 保持听觉带 [0.5h, h] | 距离 < hearRange |
| **ISOLATED** | 独白（完全隔离） | 避让 ≥60 格 | 距离 ≥ hearRange / 秘密任务 |

**冲突优先级**：ISOLATED 避让 > WEAK 保持距离 > MERGED 跟随；玩家手动目标不被覆盖。

## 关键机制
- **Arbiter 脱敏**（生死线）：`sanitizeSummaryForArbiter()` — Arbiter 永远看不到轨道全文，只看脱敏摘要（防信息源泄露）
- **TrackScore 因子**：size 30 / bystander 20 / conflict 30 / **secret 50** / emotion 25；阈值 40
- **秘密任务**：`TrackDirectorService.setSecretAgents()` → 强制 ISOLATED；`InteractionDetector.evaluate(agents, secretTaskAgents)` +50
- **多群组**：ModeClassifier 听觉连通分量分组 + Virtual Threads 并发，TrackStrategy 只影响组内上下文
