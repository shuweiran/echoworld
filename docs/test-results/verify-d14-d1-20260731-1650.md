```

  "cancelled":[{"id":"靶子二号_dialogue_5","status":"CANCELLED","stop_type":"HARD","reason":"运行时验证-精确中断",...}]}
[send finished] 200 total=8.77s {"agent_outputs":[],"status":"error: 生成已中断",...}
[final task] {"id":"靶子二号_dialogue_5","status":"CANCELLED","stop_type":"HARD","reason":"运行时验证-精确中断"}
```

- 中断即时生效：send 在中断点立即返回（8.77s），未等完整失败路径（~11.4s）→ 关联 Future cancel(true) 中断了进行中的 LLM HTTP 调用
- 任务状态机：RUNNING → CANCELLED（HARD），reason 正确携带自定义原因
