## D. 执行须知（后续开发口径，8 条）

1. **SSE 定向通道沿用 broadcastToSession**：新增 6 事件全部走既有会话定向广播（无 session 过滤连接收全局广播）；前端 3s 轮询兜底（对齐 script_status 双通道先例）；**倒计时不走事件**（前端由 status 本地计时）。
2. **前端渐进嵌入，不改路由骨架**：ChatPage 外层改三栏（左 240 / 中 flex / 右 280 + 可折叠 localStorage），面板内容先原样嵌入、行为零变化；按阶段一→二→三逐块替换（先投票页——数据契约最小；再搜证页；最后讨论页）；每步保留 `ui-proto-v2` 特性开关可回退。
3. **复用优先**：约 60% 交互零改动复用现有端点（以 §3.1 复用映射表为准）；行动条等新执行逻辑内部委托既有 search / privateSay / discussionSay，不新增第二套执行逻辑。
4. **新增端点全部挂 /api/script/**：统一错误 {error} + HTTP 200（鉴权失败 403）；鉴权 = checkPlayerAccess（player_key，与 search/vote 同款三行样板）或 X-DM-Key；新端点不触碰房间概念。
5. **新状态随快照落库、不加表**：roleLocks / abstainedVoters / trust / pressed 标记 = 内存字段 + 快照整包 JSON 加键（零迁移，对齐 decorStates 范式）；relations/unlock 角色关联不加表（clues[].unlock_role 随 contentJson 落库）。
6. **禁动清单**：RouterService / ArbiterService / 审批 / 狼人杀 / SSE 主链路（broadcast() 本身）/ static 不动；新增 helper 沿用既有模式。
7. **揭晓沿用 ScriptStatePanel 揭晓区**（L4/U5）；ScriptStatePanel 保留为「高级/兜底面板」；ScriptGalChatPanel 打字机资产复用；三页原型 CSS 抽为 React 组件样式、localStorage 折叠逻辑抽为 useCollapsibleSidebars hook。
8. **三阶段落地口径（§3.5）**：阶段一 MVP = API-1/2（行动条）、API-10（vote/status 聚合）、API-11（弃票扩展）、API-13（goal）+ SSE script_vote_progress / script_goal，约 13-18 人日；阶段二 = API-3/4（心锁）、API-5（质询）+ 可选 API-6/7/8 + SSE script_press / script_locks，约 10-13 人日；阶段三 = API-9（present）、API-12（trust）、API-14（可选）+ SSE script_present / script_trust，约 8-11 人日；总量约 31-42 人日（MVP 占 ~45%）；L1 地图 Tab、L4 揭晓原型页未含，若做各 +2-3 人日。
