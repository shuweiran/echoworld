> 落地记录：DECISION_LOG D-012；验收 A3-1~A3-4 全过（ScriptGameDiscussionTest 4 用例）；全量 135 tests 全绿。实现：ScriptGameService.startDiscussion 建讨论组→目标注入（隐藏秘密/查明真相）→轨道分配（持秘密 WEAK / 未持 MERGED）→后台虚拟线程驱动轮次（ConversationManager.createScriptDiscussionGroup + runScriptDiscussionRounds，复用 TrackStrategy）→结束自动进 VOTE；轮数可配置 `roleplay.game.discussion.max-rounds`（默认 2）；讨论 persona 不含秘密明文（A3-2）。

**做什么**
1. `startDiscussion`（L246-251）从"只改 phase"升级为：创建讨论组 → 走对话引擎 tick 驱动 → 讨论结束返回 VOTE

3. 目标驱动：按角色秘密注入"查明真相 / 隐藏秘密"目标（WorldDirectorService.setGoal）
4. 讨论期间的搜证摘要用 EavesdropSummarizer 生成

**改哪个文件哪个位置**
- `src/main/java/com/roleplay/engine/service/ScriptGameService.java`：startDiscussion（L246-251）+ game 内部类补讨论上下文引用
