## 一、一般模式（自由角色扮演 / 对话主链路）

|---|---|---|---|

| 一般模式 | Agent / 角色（Character） | 对话参与方（AI 或玩家绑定的角色）；角色数据存 `characters` 表 | `CharacterEntity`；`/api/characters`；`POST /api/send` 中 agent 名 |

### 1.2 回合流程与状态术语

| 场景 | 核心术语 | 含义 | 使用示例/出现位置 |
|---|---|---|---|
| 一般模式 | `runRound`（回合） | 主对话链路：每轮 = 角色们各发言一轮；`roundCount` 递增 | `RouterService.runRound()`；`POST /api/send` |
| 一般模式 | 串行调度（serial） | `roleplay.round.serial: true`：同轮按序发言、后发言者上下文含前者本轮发言（D-024/D-027） | `RouterService.executeRoundSerial`；yml `roleplay.round.serial` |
| 一般模式 | 点击驱动 / 播放驱动（playback-driven） | `roleplay.round.playback-driven: true`：一轮生成完即停，等前端「播出完毕」信号（`POST /api/simulation/playback_done`）才下一轮 | `RouterService.onPlaybackDone`；`awaiting_playback` 状态键；前端 `useAutoPlaybackDone` |
| 一般模式 | 自动续轮（auto-continue-ms） | 旧机制：每轮完成后延时自动下一轮（默认 3000ms）；playback-driven=true 时被忽略 | yml `roleplay.round.auto-continue-ms`（D-056） |
| 一般模式 | 校准轮（calibrate-every） | 每 N 个 AI 自主推进轮注入校准提醒（Author's Note 式防漂移，默认 10） | yml `roleplay.round.calibrate-every`（P-0813-B/C） |
| 一般模式 | 发言超长提醒（remind-threshold） | AI 单次发言中文字数 > 阈值（默认 150）→ 下一轮自动注入「请精简输出」提醒，仅下一轮生效 | yml `roleplay.llm.remind-threshold`；`Agent.appendReminder`（D-051） |
| 一般模式 | Arbiter（仲裁者） | LLM 汇总/整合每轮发言，产出旁白（narrator）与轨道分配建议；输入经脱敏 | `ArbiterService.sanitizeSummaryForArbiter()`（D-001）；`arbiter_integrate` SSE |
| 一般模式 | 记忆压缩链（Memory / Compressor） | 短期窗口（`short-term-rounds: 20`）+ 摘要链（`summary-interval: 10` 轮压缩），控制 token 成本 | `MemoryStore` / `Compressor` / `MemoryRetrieval`；`compression` SSE |
| 一般模式 | visibleTo / 上下文可见性 | 消息对哪些角色可见的过滤机制（Track 隔离的落点） | `Message.visibleTo`；`getMessagesVisibleTo` |
| 一般模式 | 私聊（PrivateChat） | 玩家之间/与角色的私聊请求-回复-发送 | `PrivateChatService`；`/api/private_chat/request` `/reply` `/send` |
| 一般模式 | 聊天命令 | `/mode` `/goal` `/protagonist` `/restrict` `/stop` `/end` `/status` | README「自由对话/角色扮演」模块 |
| 一般模式 | 回合回滚（rollback） | 回滚到指定回合（上限 50 快照） | `POST /api/round/rollback`；`POST /api/round/start`（turns 参数） |
| 一般模式 | 停止（stop） | 中断进行中的 LLM 生成（HARD/SOFT/STATE_INVALID） | `POST /api/stop`；`/api/interrupt` |
