# 当前维护状态

> 最后更新：2026-08-24。本文是项目“现在该做什么”的短入口；历史细节分别保留在 `DECISION_LOG.md`、`TEST_STATUS.md` 和 `docs/修改记录.md`。

## 当前定位

EchoWorld 是 Java 空间多 Agent 仿真项目：React/Phaser 提供地图与交互界面，Spring Boot 提供权威空间状态、听觉、上下文隔离、对话和场景逻辑。一般模式、剧本杀和狼人杀是验证社会互动与隐藏信息边界的应用场景。

## 桌面版状态

- 桌面壳、固定 16:9 窗口、内置 Java、后端本机启动与安装目录外数据存储已经完成验证。
- 历史 `0.1.0` 候选因曾把签名 PFX 打入 ASAR，已作废并禁止分发；源码 PFX 与前端候选目录已清理，根 `release` 残留由当前 Codex 文件句柄占用，退出 Codex 后删除。
- 当前**没有可分发桌面候选**。后续候选必须通过 ASAR 敏感扩展扫描、当前 JAR 版本门禁和干净账户验收。
- 正式构建已改为 staging 门禁：只接收本次生成的可执行 Spring Boot jar、`runtime-release` 和 HTTPS 更新地址。
- 自动更新流程、候选构建、更新清单和回滚规则见 [桌面版维护与更新流程](桌面版维护与更新流程.md)。

## 当前优先级

1. 退出 Codex 后删除根 `release` 作废候选；如该 PFX 曾用于真实签名，应轮换/吊销对应证书。
2. 获得可创建临时 Windows 账户的提升权限，补做真实“干净 Windows 账户”验收；当前已用全新用户数据目录完成同等安装/启动/存档/升级验证。
3. 准备 Windows `.ico` 与新的 Authenticode 代码签名，再考虑公测或正式发布。
4. 按页面逐步把既有业务 UI 对齐 [UI 视觉规范](UI视觉规范-图标标签清单.md)，不以桌面壳替代业务页质量改造。
