## 1. 测试目标

1. **全功能覆盖**：后端 **110 个 HTTP 端点**（17 个 Controller，2026-07-31 逐条核实）+ 前端 4 页面全流程 + 2D 独立页，逐项给出可执行用例（**93 个后端用例覆盖 110 个端点**；前端 **29 个手动用例**），做到"有方法、可执行、有结论、无遗漏"。
2. **超长文本稳定性**（需求硬性要求）：至少 1 次专门用例。本方案给出 **LONG-01~04 四组用例**，并记录已执行历史（v1 LONG-01 累积版即 v2 LONG-02：首跑失败→复跑通过，见 §10.2）。
3. **回归安全**：以 93 tests 为基线，补齐 P0 缺口（Controller 层集成测试、游戏状态机、前端契约断点），保证每轮迭代 `mvn test` 全绿。
4. **缺陷显性化**：19 项设计差异 D1–D19 逐项给出验证用例；已知缺陷预期写"按缺陷现状验证 + 标记为已知缺陷 + 修复后预期"，输出可跟踪的失败证据，不掩盖、不删除。

## 3. 测试分层（5 层）

```
┌─ 1. 单元测试（JUnit5 + Mockito，mock LLMClient/HTTP）
│    目标：毫秒级验证纯逻辑正确性（规则、状态机、边界、脱敏），无 IO、无网络
│    命令：mvn test -Dtest=XxxTest
├─ 2. 集成测试（@SpringBootTest(RANDOM_PORT) + MockMvc + H2 独立库 mem:testdb + @MockBean LLMClient）
│    目标：验证 Spring 装配、Controller 全端点（110 个）、DB 持久化、SSE 生命周期、状态机非法流转
│    命令：mvn test -Dtest=XxxControllerTest
├─ 3. E2E 测试（Python3 UTF-8 + requests，打现网 8000 实例）
│    目标：验证真实链路（HTTP → 服务 → 真实 LLM → SSE/前端），冒烟 S1–S12 + 前端联调
│    命令：python scripts/smoke/smoke_basic.py
├─ 4. 回归测试（mvn test 全量 + 冒烟脚本，每轮迭代必跑）
│    目标：防退化，93 基线 + 新增全绿；前端改动后 npm run build 同步 static/ 再手动回归
└─ 5. 稳定性测试（JUnit 长文本用例 + Python 压测 + 堆/耗时观测）
     目标：长文本不崩溃/不 OOM/响应可接受/内容不丢失（LONG-01~04，§10）
```

**关键取舍**：
- LLM 调用是真实付费 API 且现网实例**当前 401** → 单元/集成测试一律 mock `LLMClient`；仅 E2E 冒烟与限量抽样走真实 LLM，**LLM 401 未修复时，依赖真实 LLM 的用例如实记录为环境阻塞，不删除、不伪装通过**。（**G1 已于 2026-07-31 21:35 解除**，见台账 #28：key 在用户环境变量 ROLEPLAY_LLM_API_KEY，D25 后启动自动读取；本条约束适用于未配置 key 的环境）
- 后端 8000 端口正在运行且禁止 `spring-boot:run` → 集成测试用 `RANDOM_PORT` 独立实例；E2E 打现网但用独立 session_id，跑完清理。
