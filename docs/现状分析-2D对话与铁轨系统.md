# 现状分析：2D 对话系统 vs 需求文档目标架构

> 分析日期：2026-07-31
> 依据：源码阅读（ConversationManager / GroupStrategy / DebateStrategy / ModeClassifier / HearingSystem / RouterService / ArbiterService）

---

## 一、现状：2D 对话系统（已实现）

### 1.1 对话触发链

```
SimulationWorld.tick()
  → ConversationManager.tick(now)
    → HearingSystem.computeAudibility(allStates)   // 距离 → 可听矩阵
    → ModeClassifier.classify(hearing, available)   // 连通分量 → 对话候选组
      → 情绪(ANGRY≥2) + 立场(FOR/AGAINST) → DEBATE
      → 1人 + 有人听 → PUBLIC_SPEAKING
      → 2人 → DYAD
      → ≥3人 → GROUP_DISCUSSION
    → startGroup(gid, mode, members)
      → 对应 Strategy（Dyad/Group/Debate/Speech）
      → 虚拟线程并行调 LLM → latch 等待
      → processResults → 情绪识别、消息落地
```

### 1.2 现有策略覆盖

| 策略 | 模式 | 行为 | 信息隔离 |
|------|------|------|---------|
| DyadStrategy | DYAD | 双人轮流发言 | 无（两人全量共享） |
| GroupStrategy | GROUP_DISCUSSION | 2 人 active + 其余 listener | **无**（listener 也拿完整聊天记录） |
| DebateStrategy | DEBATE | 立场辩论 | 无 |
| SpeechStrategy | PUBLIC_SPEAKING | 独白 | 无 |

### 1.3 关键缺陷（与需求文档对照）

1. **信息零隔离**：GroupStrategy 的 `buildContext()` 中，listener 与 active 一样拿到完整 `【聊天记录】`（最近 8 条）。旁观者 C 完全知道 A、B 的私密讨论内容——不符合"空间监听"语义。
2. **无 Track 概念**：2D 对话完全没接 Track 系统。Track（MERGED/WEAK/ISOLATED）只存在于主对话 RouterService 中。
3. **无偷听摘要机制**：C 在旁边应该"听见声音、获得摘要、不进入上下文、不调用 LLM"——现状是 C 直接进对话组拿全文。
4. **模式切换是硬规则**：ModeClassifier 用 if-else 规则（情绪/立场/人数），没有 InteractionDetector 的轻量评分（TrackScore）。
5. **无中断系统**：Agent 生成中世界状态变化（玩家打断、轨道变化）无法终止 LLM 输出。
6. **无运动约束**：没有 MovementConstraint——WEAK 角色应保持听觉范围、ISOLATED 应主动远离，现状角色无社交性移动。

## 二、需求文档目标架构（要实现的）

### 2.1 三层融合

```
物理世界 (position/distance/hearing)
    +
社会世界 (track/visibility/relationship)
    +
认知世界 (memory/goal/intention)
```

### 2.2 核心新增组件（Phase 1）

| 组件 | 职责 |
|------|------|
| `TrackAssignment` | agent → TrackType + visibleAgents + 上下文权限 |
| `SpatialTrackResolver` | 距离 → 轨道分配（<5 WEAK_TRACK / privateRoom ISOLATED / 否则 MERGED） |
| `InteractionDetector` | 轻量规则评分 TrackScore（人数/旁观者/目标冲突/秘密任务/情绪异常） |
| `ContextVisibility` | 上下文可见性过滤 |

### 2.3 三级社交状态模型

- Level 0 普通交流（2人 DYAD）
- Level 1 空间监听（C 听摘要，不进上下文，不调 LLM）
- Level 2 Track 模式（MERGED/WEAK/ISOLATED）
- Level 3 剧情 Track（狼人杀/剧本杀，Arbiter 参与）

### 2.4 中断系统

- InterruptManager + AgentTaskManager + CancellationToken
- 硬停止 / 软停止 / 状态失效停止
- 事件驱动（WorldEventBus）

## 三、可量化差距（替换前 → 替换后）

| 指标 | 现状 | 目标 | 说明 |
|------|------|------|------|
| 旁观者上下文泄露 | 100%（listener 拿全文） | 0%（仅摘要） | 信息隔离度 |
| 旁观者 LLM 调用 | 每轮必调 | 0 调用（仅摘要） | 成本 |
| 多人对话上下文 token | 全量共享，随人数线性增长 | 按轨道裁剪 | 上下文爆炸 |
| 秘密/私聊支持 | 无 | ISOLATED 隔离 | 剧情张力 |
| 社交性移动 | 无 | 跟随/保持距离/回避 | 真实感 |
| 生成中断 | 无 | 硬/软/状态停止 | 实时性 |
