# Roleplay Engine 社区发布素材

仓库：[https://github.com/shuweiran/echoworld](https://github.com/shuweiran/echoworld)

## 英文短文案（X / Reddit / Hacker News）

I built an open-source AI roleplay engine where multiple LLM characters move and interact in a 2D world. It combines character chat, spatial context visibility, Phaser maps, Werewolf, and a full Script Murder loop: investigation → discussion → voting → reveal.

The repo includes real gameplay screenshots, a Java 21 + Spring Boot backend, React + Phaser frontend, and 985 passing backend tests.

Try it locally and let me know which character or game mode you would add: https://github.com/shuweiran/echoworld

## 中文短文案（知乎 / V2EX / Discord）

这是一个开源 AI 多角色互动引擎：多个 LLM 角色可以在 2D 空间中移动、感知和对话，并参与狼人杀、剧本杀完整流程。项目把角色聊天、空间上下文隔离、Phaser 地图、TTS 和剧本杀搜证/讨论/投票/揭晓放在同一个 Java + React 工程里。

仓库里有真实运行截图、5 分钟启动说明和完整测试基线，欢迎 Star，也欢迎提 Issue 分享你想玩的角色或剧本：

https://github.com/shuweiran/echoworld

## 发布建议

1. 首发贴只放 1 张最能解释玩法的截图，正文链接 README；评论区再补完整流程截图。
2. 标题优先强调用户能看到的结果，例如 “An open-source AI roleplay engine where LLM characters move and investigate in a 2D world”。
3. 发布后 24 小时内回复每条技术问题，并把高质量问题转成 GitHub Issue。
4. 不要批量重复发相同内容；按社区规则分别调整语言、截图和技术细节。
