Phaser 3.90 以本地 vendor 文件引入（vendor/phaser.min.js，npm phaser@3.90.0 提取），不依赖 CDN（国内网络可用性 + file:// 兼容）；CDN 备选：https://cdn.jsdelivr.net/npm/phaser@3.90.0/dist/phaser.min.js。
素材为程序生成占位帧（tools/gen_assets.js，零第三方版权）。file:// 打开时资源自动走内嵌 base64（js/assets_embedded.js），http 打开时走真实文件管线。详见 README.md。
